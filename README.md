### 简介

QuickConvert 是一款纯离线万能换算工具。**两个版本**：Windows 桌面 exe 双击即用，**单文件 HTML Web 版用浏览器打开就行**——电脑、手机、平板全通用。13 个类别、300+ 单位，切换基准单位，每条结果附带生活类比。

### 🚀 两个版本

| 版本 | 适用平台 | 文件 |
|------|------|------|
| 💻 **桌面版** | Windows (.exe) | QuickConvert.exe (12MB) |
| 🌐 **Web 版** | Windows / macOS / Linux / 安卓 / iOS | quickconvert.html (单文件) |

Web 版打开即用，无需安装——浏览器打开就能换算。另存到本地可完全离线使用。

- 🔢 **13 个类别** — 长度/重量/温度/面积/体积/速度/数据/角度/能量/压力/货币/时区/尺码

- 👕 **鞋码对照** — 中国码/美国码/英国码/欧洲码互查
